搭建个人网站时，最容易陷入的误区是“技术栈越复杂越显得专业”。但在真实维护半年之后，决定你是否愿意继续更新的，往往只有两件事：**写作阻力有多低**，以及**页面打开有多快**。

## 为什么选择 Astro

Astro 的核心理念非常适合个人站点：默认输出零客户端 JavaScript 的纯静态 HTML，仅在确实需要交互的地方补充极少量脚本（比如主题切换或标签筛选）。

- **原生 Content Collections**：通过 Zod Schema 对每篇 Markdown 的标题、日期与标签做静态类型校验，写错 Frontmatter 会在构建阶段直接提示。
- **开箱即用的双主题代码高亮**：借助 Shiki，可以在浅色与深色模式下保持清晰柔和的语法配色。
- **零门槛部署**：`npm run build` 生成纯静态 `dist/` 目录，可无缝托管在 Cloudflare Pages、Vercel 或 GitHub Pages。

## 克制的视觉设计原则

> 好的极简设计不是把元素删到空无一物，而是让每一处留白、字号与对比度都在为阅读服务。

在这套主题中，我特意做了几个看似微小却直接影响观感的决定：

1. **用温润纸白替代刺眼纯白**：浅色背景采用 `#FAF9F6`，深色背景采用 `#0C0C0E`，长时间阅读眼睛更轻松。
2. **消除深色模式切换闪烁（No-FOUC）**：在 `<head>` 顶部同步读取 `localStorage` 与系统主题偏好，页面首次绘制前即确定 `.dark` 状态。
3. **集中式配置**：个人资料、导航与经历统一放在 `src/config/site.ts`，避免改一个邮箱要翻遍七八个文件。

```ts
// src/config/site.ts 中的单一数据源示例
export const siteConfig = {
  name: '微微笑的蜗牛',
  role: '全栈开发者',
  email: '413769707@qq.com',
};
```
